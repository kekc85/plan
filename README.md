# AeroPlan W&B — Электронный суточный план диспетчера по центровке

> **Версия:** `v1.0.1` (25.08.2026)  
> **Разработчик:** Andrey Zubkov  
> **Репозиторий:** [https://github.com/kekc85/plan](https://github.com/kekc85/plan)

Современное специализированное веб-приложение для ведения суточного плана группы центровки и контроля загрузки воздушных судов (Weight & Balance / Load Control) с прямой интеграцией с порталом **AviaBit** (Nordwind / Икар).

---

## ✈️ Основные возможности

1. **Интерактивный журнал суточной смены**:
   - Живая таблица рейсов с поддержкой перетаскивания строк (Drag-and-Drop) и авто-сортировки по времени вылета.
   - Учёт 24-часовой смены (09:00 — 09:00) с автоматическим разделением дней и маской даты (`25.08`).
   - Автоматический расчет времени выпуска рейса (**ВЫП = ВЫЛ - 40 минут**).
   - Быстрые статусы рейсов: *⚪ Ожидание*, *🟡 В работе*, *🔵 Подготовлен*, *🟣 LIR отправлен*, *🟢 Выпущен*, *⚫ Закрыт*.
   - Отметки готовности документов: **LIR**, **СЗВ**, **LDM**.

2. **Прямая интеграция с AviaBit**:
   - Быстрая многопоточная выгрузка расписания (Nordwind / Икар) напрямую через REST API.
   - Фильтрация по разрешенным аэропортам, бортам, экипажам (`Л/Б/И/П`) и пассажирам.

3. **100% нативный экспорт и импорт Excel (.xlsx)**:
   - Серверный генератор на базе `openpyxl`, в точности повторяющий канонический вид суточного плана (шрифты Calibri, рамки, вертикальный поворот текста для СЗВ/ЛДМ, альбомная печать А4 `fit-to-page`).
   - Импорт любых внешних файлов Excel со структурой плана.

4. **Звуковое и визуальное оповещение о выпуске**:
   - При наступлении времени выпуска рейса всплывает окно напоминания с возможностью выпуска в 1 клик.
   - Приятный двухтональный авиационный сигнал оповещения (*Ding-Dong*, Web Audio API, работает офлайн).

5. **Безопасность и конфиденциальность**:
   - Пароли и параметры доступа вынесены в изолированный файл `.env` и исключены из репозитория.

## 🚀 Быстрый запуск

### 1. Настройка окружения
Создайте локальный файл `.env` в корне проекта (на основе `.env.example`):
```env
AVIABIT_USERNAME=ваш_логин
AVIABIT_PASSWORD=ваш_пароль
PORT=8000
```

### 2. Установка зависимостей
```bash
# Python бэкенд
pip install -r requirements.txt

# React веб-приложение
cd web_app
npm install
```

### 3. Запуск одной кнопкой (Windows)
Просто запустите файл:
```text
Запуск_Веб_Журнала.bat
```
Приложение откроется в браузере по адресу: **`http://localhost:5173/`**

## 🛠 Технологический стек
- **Frontend**: React 18, Vite, Tailwind CSS, Lucide Icons, @dnd-kit (Sortable Drag & Drop).
- **Backend**: Python 3.12, FastAPI, Uvicorn, Requests, OpenPyXL.
- **Audio Engine**: Web Audio API (чистый синтез сигналов без сторонних библиотек).
