# State Log: Parser Aviabit

- 2026-08-24: Исследована структура API сайтов Nordwind (aviabit.nordwindairlines.ru) и Икар (aviabit.ikar.aero).
- Реализована мульти-серверная архитектура с объединением расписаний Nordwind + Икар в один суточный план.
- Добавлена поддержка 2FA-кодов подтверждения из почты:
  - Автоматический диалог ввода 4-значного кода в GUI и консоли.
  - Долговременное кэширование авторизационной сессии Икар в `.session_ikar.json`.
- Доработана логика по замечаниям:
  1. PAX, NOTES: считается сумма первых двух чисел (взрослые + РБ), РМ (инфант без места) не учитывается.
  2. Экипаж: формат строго 4 цифры через слеш (Летный/Бортпроводники/ИТС/Пассажиры), в шапку добавлена расшифровка первых букв: `Экипаж\nЛ/Б/И/П`.
  3. Маршрут: город ПРИЛЁТА сверху (согласно коду IATA из расширенного справочника или динамически из ответа сервера `preliminary[1]["airportName"]`), DEP-ARR снизу (например Казань\nSUI-KZN, Москва\nSUI-SVO, Сыктывкар\nAER-SCW).
  4. Топливо: ячейка остается пустой с сеткой под ручной ввод диспетчером.
  5. Шапка таблицы: выделена жирными (medium) границами со всех сторон каждой ячейки. Колонки СЗВ и ЛДМ — с вертикальной ориентацией текста (90 градусов).
  6. Страница печати Excel: альбомный лист А4, минимальные верхние/нижние/боковые поля (0.2-0.25 in), отключено вертикальное центрирование (таблица начинается сразу сверху как на образце), авто-ширина без сжатия в миниатюру.
  7. Шрифты: основной текст таблицы и шапка — Calibri 11 (рейс обычным шрифтом, PAX жирным), колонка маршрута с городами — Calibri 9.
  8. Защита от блокировки файлов Excel: при открытом файле в Microsoft Excel парсер автоматически сохраняет копию с суффиксом `(1)`, `(2)` и сообщает точный путь без сбоя программы.
  9. Числовые ячейки: Номер ВС, Компановка и PAX записываются в Excel как целые числа (`int`), что полностью убирает зеленые треугольники предупреждений «Число сохранено как текст».
  10. Иконка приложения: создана стильная авиационная иконка `app_icon.ico` (самолет над неоновой таблицей расписания) и подключена в GUI окно и панель задач Windows.
  11. Файл запуска с иконкой: создан ярлык Windows `Суточный план Диспетчера.lnk` с кастомной иконкой самолета для запуска программы в один клик без консоли.
  12. Выбор пути сохранения: при нажатии кнопки выгрузки открывается стандартное окно Windows «Сохранить как...» с предзаполненным именем файла, позволяющее выбрать любую папку (Рабочий стол, Документы, диск и т.д.).
  13. Правило для вылетов из SVO: рейсы с пунктом отправления SVO выгружаются ТОЛЬКО если количество пассажиров равно 0 (пустые/технические рейсы). Рейсы из SVO с пассажирами автоматически отсеиваются. Все остальные 25 аэропортов выгружаются в полном объеме.
  14. Актуальное Московское время вылета (ATD/ETD МСК): колонка «Время» и хронологическая сортировка таблицы теперь используют актуальное время по Москве (UTC+3) с учетом задержек (`dateTakeoffReal` -> `dateTakeoffCalculation` -> `dateTakeoff`).
  15. Выбор диапазона времени: в GUI и парсер добавлена возможность выбора времени начала (ЧЧ:ММ) и окончания (ЧЧ:ММ) по Москве. Рейсы фильтруются строго по указанному временному окну.
  16. Исключение резервов: добавлены строгие правила отсеивания любых служебных записей резерва (с красной буквой R, `~РЕЗ`, `isSpecialFlight`). В итоговую таблицу попадают исключительно рабочие рейсы.
  17. Выпадающий интерактивный календарь: в GUI текстовые поля дат заменены на выпадающие календари `DateEntry` (русская локализация `ru_RU`, формат `ДД.ММ.ГГГГ`), позволяющие выбирать даты кликом мыши по дням и месяцам.
  18. Быстрая замена значений: для всех полей даты и времени настроено автоматическое выделение содержимого при фокусе для мгновенной перезаписи.
  19. Авто-маски ввода: подключено автоматическое форматирование для ввода времени (авто-вставка двоеточия `ЧЧ:ММ`) и всеядное распознавание дат (как с точками, так и сплошных цифр `25082026`).
